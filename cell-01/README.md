# 🌐 Cell 01 — Foundations of Web Development

> *"Structure is the canvas. Tags are the paint."*

Welcome to **Cell 01**.  

This cell invites you to **step into the world of web development** — crafting your first HTML pages, playing with images, links, styling, and responsiveness.  

Every page you build here is a tiny story, a digital footprint that merges **design and code** to create a meaningful experience for anyone who visits.

<br>

## 📜 Exercises Overview

Click on the **Folder Name** to access the source code and view the rendered result.

| Exercise Folder | Task Name | Technical Objective |
| :--- | :--- | :--- |
| **[📂 ex00](./ex00)** | **Hello World** | **Initialization:** Creating the first HTML scaffolding. |
| **[📂 ex01](./ex01)** | **Titles** | **Typography:** Mastering header hierarchy (`<h1>` tags). |
| **[📂 ex02](./ex02)** | **Images** | **Assets:** Embedding media content into the flow. |
| **[📂 ex03](./ex03)** | **Links** | **Hypermedia:** Connecting nodes with Anchor tags (`<a>`). |
| **[📂 ex04](./ex04)** | **Basics** | **Styling:** CSS Backgrounds, Hex colors & Alignment logic. |
| **[📂 ex05](./ex05)** | **Tab** | **Grid Data:** Structuring information using HTML Tables. |
| **[📂 ex06](./ex06)** | **Responsive** | **Fluidity:** Implementing 100% width logic for mobile adaptation. |

<br>

## 🛠 Skills Gained

* **Semantic HTML:** Writing code that describes its content, not just its look.
* **Asset Management:** Linking local and remote images effectively.
* **Layout Engineering:** Using tables (legacy) and CSS basics to organize space.
* **Responsive Design:** Ensuring interfaces break gracefully on smaller screens without JavaScript.

<br>

## 🚀 Execution Guide

Unlike shell scripts, these files live in the browser.

### How to Render
Simply **double-click** any `.html` file, or launch it from the terminal:
```bash
# macOS
open ex04/basics.html

# Linux
xdg-open ex04/basics.html

# Windows
start ex04/basics.html
```
