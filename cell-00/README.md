# 📦 Cell 00 — Basic Shell Challenges

> *"Before the interface, there was the terminal."*

Welcome to **Cell 00**.  

This is where the journey begins — a series of **minimalist shell challenges** designed to sharpen your command-line instincts, spark curiosity, and lay the foundation for everything you'll build next.


## 📜 Exercises Overview

Click on the **Folder Name** to access the source code and specific instructions.

| Exercise Folder | Task Name | Technical Objective |
| :--- | :--- | :--- |
| **📂 ex00** | **The Basics** | **Structure:** Enforcing the strict 42 directory naming convention. |
| **[📂 ex01](./ex01)** | **Z** | **IO Streams:** Understanding `cat` and standard output formatting. |
| **[📂 ex02](./ex02)** | **midLS** | **Listing:** Customizing `ls` with comma-separation and zero-newline. |
| **[📂 ex03](./ex03)** | **count_files** | **Piping:** Chaining `find` and `wc` to count nodes recursively. |
| **[📂 ex04](./ex04)** | **argv** | **Arguments:** Handling input parameters (`$1`, `$2`...) inside a script. |
| **[📂 ex05](./ex05)** | **build** | **Automation:** Using loops (`for`) to generate bulk directory structures. |

<br>


## 🛠 Skills Gained

* **FileSystem Navigation:** Moving through the hierarchy without a mouse.
* **Pipeline Logic:** Connecting commands (`|`) to filter and process data streams.
* **Argument Parsing:** Creating scripts that react to user input.
* **Permissions:** Understanding `chmod` and the execution bit (`+x`).

<br>

## 🚀 Execution Guide

To run these scripts, you must first grant them execution rights within the terminal.

**1. Grant Permission**
```bash
chmod +x script_name.sh
```
**2. Execute**

For standard scripts:
```bash
./script_name.sh "Argument 1" "Argument 2"
```

For the 'Z' exercise (Stream test):
```bash
cat ex01/z
# Output: Z
```
