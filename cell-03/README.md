# 💻 Cell 03 — Interactive Web with JavaScript & jQuery

> *"Static pages are just documents. Scripts make them applications."*

Welcome to **Cell 03**. 
  
This cell marks your leap into **dynamic and interactive web development**.  

Using standard JavaScript — and later jQuery — you will bring your pages to life with user events, animations, and real-time interactions.  

Each exercise is a step toward mastering how **code and user experience blend**, creating responsive, fun, and useful web applications.

## 🛠 Skills Gained

* **DOM Manipulation:** Selecting, creating, and destroying HTML elements on the fly.
* **Event Architecture:** Understanding the event loop, propagation, and listener attachment.
* **State Management:** Keeping track of variables (like balloon size) across interactions.
* **Client-Side Storage:** Using Cookies to save user data so it survives a page refresh.
* **Progressive Enhancement:** rewriting verbose Vanilla JS into efficient jQuery scripts.
