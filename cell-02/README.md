# 🚀 Cell 02 — Advanced CSS & Interactive Web Elements

> *"Code usually runs the logic. Here, style runs the behavior."*

Welcome to **Cell 02**. 

This cell elevates your web development skills with **responsive design, interactive menus, visual effects, and user interface components** — all without touching JavaScript.  

Here, you learn to create **dynamic, beautiful, and user-friendly experiences** using just HTML and CSS — mastering the subtle art of crafting modern web interfaces.

<br>

## 📜 Exercises Overview

Click on the **Folder Name** to access the source code and view the rendered result.

| Exercise Folder | Task Name | Technical Objective |
| :--- | :--- | :--- |
| **[📂 ex00](./ex00)** | **Responsive Upgrade** | **Fluidity:** Converting fixed tables into percentage-based fluid layouts (`width: 100%`). |
| **[📂 ex01](./ex01)** | **SNCF Menu** | **Zero-JS Interactivity:** Building a functioning "Hamburger" dropdown using only CSS selectors. |
| **[📂 ex02](./ex02)** | **Parallax** | **Visual Depth:** Creating 3D scrolling effects using `background-attachment` and Z-layers. |
| **[📂 ex03](./ex03)** | **Profile Card** | **Component Design:** Architecting a polished UI card with social icons and layout constraints. |

<br>


## 🛠 Skills Gained
* **Advanced Viewport Control:** Making content adapt gracefully from Mobile to Desktop.
* **Pseudo-Class Logic:** Using HTML state (like checkboxes) to trigger CSS animations.
* **Visual Engineering:** Implementing Parallax scrolling for immersive depth.
* **Component Architecture:** Structuring reusable UI elements like Cards and Navbars.

<br>

## 🚀 Execution Guide

These files rely heavily on modern CSS engines.
